Change Admin Password

Update your admin login credentials

Admin credentials are stored in your .env file. To change them, update the file directly and restart the server: 
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_new_password

The .env file is located at D:\organic-soap-store\.env
After updating, restart the server with npm start or node server.js.
